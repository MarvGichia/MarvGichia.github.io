## Project Overview

A full-stack online bookstore system built with the Django framework, designed to streamline book management, customer interactions, and purchase workflows. The system provides an intuitive interface for both administrators and shoppers, integrating secure authentication, dynamic content rendering, and database-driven operations.

### Key Features

- Role-based authentication using Django’s built-in auth system, including secure session handling and form validation.
- Administrator dashboard for uploading books, updating metadata, tracking orders, and managing inventory.  
- Customer storefront with book browsing, cart functionality, and checkout capabilities backed by SQLite3 transactions.  
- Responsive UI implemented using HTML, CSS and Javascript to deliver MIS-style user experience suitable for academic and demo environments.

### Tool Stack

- Python (Django), SQLite3  
- HTML5, CSS3, JavaScript  
- Django ORM, Django templates  
- Git/GitHub for version control
